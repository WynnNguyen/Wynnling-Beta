# Wynnling Beta

Public GitHub Pages beta for testers. The main Wynnling source repository is private.

This website is publicly accessible. The noindex directive discourages search indexing but does not restrict access or downloads.

All rights reserved.

## Development and quality checks

Run `node tests/check.cjs` with Node.js 22. No dependency installation or build step is required. The same command runs in GitHub Actions.

See [the comprehensive audit report](AUDIT-REPORT.md) for verified findings, changes, test coverage and remaining review items, and [the architecture map](audit/ARCHITECTURE.md) for the current script/data flow.
